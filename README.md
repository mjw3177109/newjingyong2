# 竹影江湖 · HTML5 Q版国风武侠 RPG

此仓库的目标是参考已有 `jin.swf` 的可核实剧情流程，重制为纯 HTML5 浏览器游戏，全部画面采用自创 Q 版国风。**目前是可游玩的原创机制演示，不是原作剧情完整移植，也不是已完成的 1:1 复刻。**

## 本地运行

```sh
# 不需要安装 Flash / npm 依赖
python3 -m http.server 5173
# 浏览器访问 http://localhost:5173

# 另一个终端执行逻辑测试（需要 Node 18+）
npm test
```

方向键或 WASD 移动、E 与角色交互、B 查看背包、J 查看任务；手机屏幕下显示方向按钮。靠近竹隐老人领取任务，草药拾取、击败右侧敌人、复命。浏览器内「保存进度」「读取进度」使用 `localStorage`。导入 JSON 存档会先预览任务、气血和银两，需确认后才替换当前未保存进度；取消导入不改变当前进度，确认导入也不会自动覆盖本机存档。

## 项目结构

- `src/engine.js`：纯 JS 角色、背包、任务、战斗与存档状态转换，单元测试覆盖。
- `src/main.js`：Canvas 2D 原创地形绘制、SVG 精灵、键盘触屏操作。
- `assets/*.svg`：原创 Q 版角色/草药示范素材；尚未扩展为全套素材。
- `tools/inspect_swf.py`：本地或 GitHub Actions 中的只读 SWF 结构清点，生成报告。
- `tools/extract_reference.sh`：Java 8 + 仓库 FFDec 的分析入口；不应公开上传解编译原文。
- `docs/ROADMAP.md`：重制里程碑与实际验收标准。

## 原作剧情和版权
`jin.swf` 是历史参考文件；不可把游戏原始 SWF 美术/音乐直接用作新作资源。当前尚未验证解编译内容，`src/demo-data.js` 是**原创演示数据**。若要公开发行忠于原作的故事和角色，需要先确认取得改编、游戏使用和商业发布所需的授权。

读取本机存档前会显示任务进度、气血与银两，并要求确认；取消读取不会覆盖当前未保存进度，也不会改变本机检查点。导入 JSON 存档同样需要确认，且不会自动写入本机存档。上述均为原创试玩功能，不是原作剧情还原。
