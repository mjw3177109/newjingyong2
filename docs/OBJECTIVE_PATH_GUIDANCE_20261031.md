# 原创试玩：可行走的任务路线提示（2026-10-31）

本次只改进原创 HTML5 试玩，不声称恢复了原始 `jin.swf` 的地图、剧情或寻路机制。

- `src/objectives.js` 新增 `pathToObjective(state)`：在 25×15 原创地图上使用四方向 BFS，计算到当前任务目标**相邻可交互格**的最短步行路线，不穿过房屋或仍存在的 NPC/草药/敌人。
- 地图上以浅金色小点标注路线；任务面板显示剩余步数，抵达相邻格后提示按 E 交互。采集或击败对象后，其已移除格可正常通行。
- 无目标、状态异常或无路可走时返回 `null`；已在可交互位置返回空数组。只读计算，不改变存档结构、人物坐标或任务旗标。
- 新增 6 项 Node 回归测试：最短路、交互距离、碰撞避让、对象移除、非法状态及纯函数稳定性。
- 验证：`npm run check`；需要人工复验浏览器 Canvas 的金点与文字显示、不同窗口尺寸的操作感。

**权利与证据边界**：原作已语义核实的剧情事件仍为 **0**。本次路线是原创演示功能，不能写入原作事件对照表，也不复用原始 SWF 美术或音频。
