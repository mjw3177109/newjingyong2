# 原创 HTML5 试玩：战斗招式与装备反馈一致性（2026-11-02）

## 发现问题

试玩角色尚未取得或装备竹纹短剑时，普通攻击日志仍声称使用“青竹剑”。这与实际 12 点徒手伤害及装备后 16 点伤害不一致；战斗按钮也未向玩家说明当前招式和伤害。

## 最小修复

- `src/engine.js`：新增仅供原创试玩的 `attackName(state)`，未装备为“拳脚”，装备竹纹短剑为“青竹剑”；攻击日志统一使用此函数。
- `src/main.js`：战斗按钮显示当前招式和本次基础伤害，装备/卸下后自动刷新。攻击数值、回合顺序、存档格式及任务逻辑不变。
- `tests/combat-feedback.test.mjs`：新增徒手实战日志、数值、存档及合成装备战斗回归。
- `tests/browser_smoke.py`：增加真实 Chromium 徒手攻击日志与装备后按钮文案断言。

## 验证方法与限制

执行 `npm run check`，并在具备 Playwright/Chromium 的环境执行 `python tests/browser_smoke.py`。CI 的 FFDec/SWF 作业与本次试玩 UI 修复是独立验证；以本次提交触发的 GitHub Actions 结果为准。

当前演示任务在首次战胜试炼者后才奖励竹纹短剑，而试炼者会消失，所以“装备后 16 点伤害”在现有完整玩家流程中还没有可重复的实战目标。测试使用合成战斗状态验证装备数值，不将其误称为已开放的二周目战斗。后续可单独设计原创重复挑战，同时维护旧存档兼容性。

**所有招式、数值、任务与美术均属于原创试玩，未从 `jin.swf` 验证。** 原作剧情事件语义核实仍为 0；PR 保持 Draft，不修改 main、原 SWF 或其他仓库。
