# 原创 HTML5 试玩：Canvas 点按单步寻路（2026-11-02）

本次只增强原创 Q 版国风 HTML5 试玩，不宣称还原原始 `jin.swf` 的地图、任务或战斗。

## 发现的问题
移动端虽有方向键和任务路线按钮，但无法直接点按地图上的位置来选择行走方向；桌面鼠标同样只能使用键盘或按钮。

## 最小实现
- 新增 `src/tile-path.js`：按四方向 BFS 计算到指定可行走格的最短路线；点按仍存在的 NPC、草药或试炼者时，路线止于相邻可交互格，不穿过演员或房屋。
- `src/main.js` 将 Canvas 的鼠标点击和移动端触屏点击映射为地图格坐标；**每次点击只前进一步**，不自动触发对话、拾取、战斗或消耗物品。
- 对话和战斗期间忽略点按移动；已采集草药和已击败试炼者所在格恢复可通行。
- 不改变存档版本、角色/场景美术、任务条件或原始 SWF 文件。

## 验证
- `node --test tests/tile-path.test.mjs`：6 项单元测试覆盖最短路、活跃 NPC 避让、对象移除、非法输入、原地目标和纯函数不变性。
- `tests/browser_smoke.py`：增加真实 Chromium 桌面鼠标和移动端触屏点按单步移动、保存坐标验证；最终结果以对应 GitHub Actions 为准。

## 剩余边界
- 点击不会自动连续行走；需要重复点击或使用既有任务路线一步按钮。
- 原始 SWF 剧情、地图、战斗数值尚无已完成语义核实的事件记录（0 条），本功能不能计入原作剧情还原进度。
- 发布任何含受保护第三方剧情的商业版本前仍须确认改编和发布权利。
