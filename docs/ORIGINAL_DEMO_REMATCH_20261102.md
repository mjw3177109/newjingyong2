# 原创 HTML5 试玩：竹影再试（2026-11-02）

## 发现问题

首次完成「竹影试炼」后，蒙面试炼者在地图上消失，玩家取得并装备竹纹短剑后没有第二场可玩的战斗；装备后的 16 点攻击只能用合成状态测试。

## 最小实现

- `src/engine.js`：新增 `canRematch` / `startRematch`。仅当原创演示任务完成、靠近竹隐老人、无对话且不在战斗时，允许开启 28 气血的再次试炼。每次战斗按既有攻击/防御/服药/撤退规则运行；胜利不重复发放银两或武器。
- `index.html`、`src/main.js`：增加「竹影再试」按钮，只有符合条件时可用。键盘、触屏、普通 NPC 对话及原地图不变。
- `parseSave`：不新增字段、不升级版本；仍接受首次战斗的原位置和结构，另外允许「任务已完成、在竹隐老人邻格」的再次试炼中途存档。保留旧 v2 已完成存档可以站在已消失试炼者格子上的规则。
- `tests/rematch.test.mjs`：覆盖真实装备后的 16 点伤害、无重复奖励、重试/撤退、入口条件、原首次战斗和旧 v2 存档兼容。
- `tests/browser_smoke.py`：在桌面 Chromium 完整演示流程中加入「领取奖励→装备短剑→再次试炼→两次攻击获胜」检查。

## 验证与边界

通过 `npm run check`、`python tests/browser_smoke.py` 和 GitHub Actions 验证（以对应提交的 CI 结果为准）。再次试炼是原创演示玩法，**不是**从 `jin.swf` 验证的剧情事件、地图或数值；不包含任何原 SWF 美术、音频或反编译源码。原作语义核实事件仍为 0，12 个优先 IF 仅完成结构定位。FFDec 仍存在历史间歇性导出漂移。PR 保持 Draft，未经授权不发布受保护剧情商业成品。
