# 根时间轴 IF 双后继预览交叉校验 V1（2026-11-02）

## 发现的问题

原始 SWF 的 IF 操作码窗口已提供 `successor_arm_windows`（分支与顺序后继的有限操作码预览），但 `tools/crosscheck_root_if_handoff.py` 只校验前驱、窗口和两个后继坐标，没有校验新预览字段。被改写的预览可能在交接审计时被误认为可信的写入线索。此处为**报告一致性风险**，不是原作剧情或运行时漏洞。

## 最小修复

仅在原有交叉校验入口新增 `_checked_successor_arms`，校验两条后继的起点必须匹配已核对坐标、固定窗口上限 8、偏移有序且无重复、操作码类别在脱敏白名单内、写入提示数与类别一致、停止原因合法、同一后继的两份预览完全相同。拒绝额外字段（例如误带的操作数或脚本内容）。

交叉报告新增 `successor_branch_write_hint_count`、`successor_fallthrough_write_hint_count`、`successor_arm_write_hints_differ`，仅用于人工审查排序；不包含 Push 操作数、变量名、脚本、图片或音频。

新增合成测试覆盖正常双后继、局部/寄存器写入提示、坐标与计数篡改、重复偏移、非法类别、私有字段和 CLI 失败时不生成输出。旧有 HTML5 游戏玩法、存档 v2 和原始 SWF 均不改变。

## 证据边界

本校验只证明**脱敏报告内部结构一致**。不能独立证明 FFDec 解编译结果、AVM1 堆栈值、写入目标、地图归属、剧情条件、执行可达性或发布权利。原作语义已核实事件保持 **0**，`ready_for_html5_mapping` 仍为 **0**。

在具备合法访问权的隔离环境中，继续以匿名 review ID 对照原始 AVM1、FFDec 私有脚本和运行时行为，人工核实后才能更新原作事件对照表。CI 结果以本提交后的 Actions 为准；PR 保持 Draft，不合并 `main`。
