# 根时间轴局部控制流图证据 V1

## 范围

在原始 `jin.swf` 的根时间轴 `DoAction` 中，仅针对既有前 50 个匿名条件审查候选，复算前序四份证据（opcode、候选队列、条件跳转边、状态访问提示），拒绝源文件 SHA-256、帧号、标签序号、字节偏移或审计报告不一致的输入。

`tools/index_root_control_flow.py` 为每条顶层 AVM1 动作记录建立**局部语法图**：普通指令按下一条记录继续，`If` 产生目标与顺序执行两个后继，`Jump` 只使用目标，`Return`/`Throw` 终止局部路径。只接受目标落在有效动作记录（含 ActionEnd）边界上的分支。

## 脱敏产物

CI `swf-inventory` 生成 `swf-root-local-control-flow` Artifact。包括源 SWF SHA-256、匿名动作标签序号、根帧号、动作哈希、分支目标/顺序后继字节偏移、语法可达记录数、不可达记录数、后向分支数、未建模控制指令数；不导出原始脚本、字符串、变量名、人物、图像或音频。

## 明确限制

- `If` 的条件真假、操作数栈和变量值**未解析**；两个后继只是语法可能性，不是运行时证实的两条剧情路线。
- `WaitForFrame`、`Try`、`With`、函数定义及嵌套函数体等行为不完整建模。局部不可达记录计数不是全游戏不可达代码结论。
- `ActionEnd` 的局部可达性不代表原作场景/任务已完成。
- 真实剧情、地图、装备、战斗数值及事件副作用仍需在授权隔离环境中通过 FFDec 与运行时证据逐条人工复核。
- `verified_story_events` 始终为 **0**，不可将候选或局部分支数量冒充剧情进度。

## 验收

运行 `python -m unittest discover -s tests -p 'test_*.py'`，覆盖压缩/未压缩合成 SWF、条件双后继、无条件跳转、后向分支、不可达记录、错误目标和证据篡改。真实 SWF 的计数及 GitHub Actions 结果以对应 CI 日志为准。
