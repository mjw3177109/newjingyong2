# 原创 HTML5 试玩目标指引（2026-10-31）

本次只改进原创演示的实际可玩性，不声称恢复了 `jin.swf` 的任务逻辑。

## 发现与最小实现

此前侧边栏仅显示任务完成标记，玩家不容易辨认下一处目标。新增 `src/objectives.js`，基于现有原创试玩的 `quest` 和 `flags` 状态，按优先级给出一个目标。Canvas 在对应现有角色/物件坐标绘制金色圆环，并在任务描述中显示下一步。

- 未接任务：拜访竹隐老人。
- 任务进行中：优先未采的清心草；已采则指向未击败的试炼者；都完成则回老人处复命。
- 任务已完成：不再显示目标圆环。
- 即使先击败试炼者、再采草，也不会指向已经消失的目标。

该功能不改变战斗、碰撞、任务奖励或存档格式；没有复用 SWF 美术、台词或素材。目标坐标来自 `src/demo-data.js` 的原创演示地图，不是原始 SWF 地图证据。

## 测试和局限

`tests/objectives.test.mjs` 覆盖未接任务、条件优先级、已完成状态、非法状态和纯函数无副作用。运行 `npm run check`。最终 CI 结果应以本次提交对应的 GitHub Actions 为准。

原始剧情已语义核实事件仍为 **0**。12 个私有 IF 审查目标仍需合法授权隔离环境内的脚本与运行时双重验证；在完成验证前，不映射为原作剧情。
