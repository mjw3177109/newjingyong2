# 竹下调息：原创 HTML5 试玩补全（2026-11-02）

## 问题与最小实现
原型受伤后主要依赖商人回春散，银两耗尽时缺少一个清晰、可控的村内恢复动作。本轮仅新增原创试玩机制：角色与竹隐老人曼哈顿距离不超过一格、没有对话或战斗、且气血未满时，可点击「竹下调息」或按 **R**，单次恢复至多 **20** 点气血。

- 只更改 `src/engine.js`、`src/controls.js`、`src/main.js`、`index.html`，新增 `tests/rest-village.test.mjs` 和本文档。
- 不自动移动、不推进任务、不改变银两、背包、装备、敌人状态、存档版本或原有键位。
- 角色不在老人身边、满血、交谈或战斗中均拒绝；按钮按同一规则禁用。恢复量按真实上限记录日志。
- 现有 v1/v2 存档结构保持不变；新增回归测试覆盖存档解析、条件限制、重复恢复、快捷键与任务奖励不变性。

## 来源与版权边界
此机制完全属于「竹影江湖」原创 HTML5 演示，**不代表** `jin.swf` 中存在竹下调息、恢复 20 点或相同 NPC 事件。既有 FFDec / AVM1 结构审计继续保留；原作剧情、地图、人物和数值均不得由此推断。原作剧情事件语义已核实数维持 **0**。
