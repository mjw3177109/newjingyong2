# 原创演示背包容量与任务奖励修复（2026-10-30）

## 问题与复现
原试玩版本允许购买至 64 格回春散，采集清心草后背包达到 65 格；在完成试炼时老人无条件赠送竹纹短剑，背包变为 66 格，导致 `parseSave` 拒绝合法游玩流程产生的存档。此前没有丢弃回春散的操作，旧存档还可能卡住任务奖励。

## 最小修复
- 背包总上限 65，商人出售回春散最多累计 63 包，预留草药与任务奖励位置。
- 采集清心草、领取奖励之前检查容量；空间不足时只显示提示，不更改任务状态、银两或物品。
- 新增“整理行囊：丢弃一包回春散”按钮，必须用户主动点击；交谈、战斗期间禁用，兼容既有满包旧存档。
- 增加 4 项 Node 单元测试：购买上限、旧存档满包复原、采集上限、丢弃动作状态限制。原有存档版本仍为 V2，未删除任何已保存物品。

## 验证范围与版权界限
本修复只涉及独立原创试玩机制，不声称已恢复原 SWF 任务、角色或装备。真实原作剧情、地图、数值及事件条件的语义核验仍为 0 条。Node 单测由 `npm run check` 执行，CI 成功后再确认通过数量。原始 `jin.swf`、`FFDec/` 和 `main` 不变。
