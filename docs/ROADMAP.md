# 金庸群侠传 Q 版国风 HTML5 项目 · 可验证路线图

> 坚持区分「已在 SWF 证实」和「原创占位演示」，禁止把演示内容说成完整剧情。

## 产品不变目标
- 以 `jin.swf` 为剧情事件与数值的**核验参考**，逐事件记录：触发场景、NPC、对话条件、任务旗标、角色成长、战斗及奖励；未提取的剧情不能凭记忆补造。
- 浏览器 HTML5 原生运行，无 Flash 插件；移动端可操作；允许逐级验收。
- 人物、地图、装备、道具、技能特效、UI 均制作独立 Q 版国风原创资源；禁止直接复制 SWF 图片、音乐、图标或逐像素描摹。
- 先核验改编授权及发布渠道；原有故事、角色、名称等可能受版权或其他权利保护，原创美术不等同于获得剧情改编发行权。

## 每轮工作记录要求
1. 核对 `main`、分支、待处理 PR、最近测试结果，先复用已完成的成果。
2. 按真实反编译数据建立 `docs/story-audit/` 对照记录，**引用对应脚本路径和行号**，不要直接把完整原始源码和美术公开重新分发。
3. 每轮 1–3 个独立、可测试的最小增量；有测试才声明功能完成；单独 PR 合并以 CI 为准。
4. 检验所有插画是原创，未复制原始素材；禁止以「已完成 1:1」概括未验证剧情。
5. 报告可点击的 commit/PR、CI、完成/未完成范围与下次改进方向。

## FFDec 分析操作
在 Java 8 环境下执行：`bash tools/extract_reference.sh jin.swf /tmp/jy2-decompiled`。
脚本原文只供授权审计，不纳入 HTML5 发布包或 Git 提交。已内置结构清点：`python tools/inspect_swf.py jin.swf --out reports/swf_inventory.json`。
