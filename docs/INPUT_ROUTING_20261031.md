# HTML5 原创试玩：键盘焦点与战斗快捷键（2026-10-31）

## 本轮问题

原有 `src/main.js` 在整个 `document` 上直接响应 Enter、空格、E、H 和方向键。焦点位于「保存」「读取」「交互」「战斗」等按钮时，浏览器的原生按钮键盘激活与全局游戏快捷键可能同时触发；长按交互键还可能反复关闭并重新打开对话。战斗只支持鼠标/触屏点击按钮，键盘操作不完整。

## 最小实现

- 新增纯函数 `src/controls.js#commandForKey`，统一解析键盘指令。
- 焦点位于按钮、表单、链接、可编辑区域或 role=button 后代时，保留浏览器原生键盘行为，不抢占事件。
- 忽略已经取消的事件、输入法组合态和 Ctrl/Alt/Meta 组合键。
- 非战斗状态：方向键/WASD 移动；E/Enter/空格交互；H 服药；B 背包；J 任务。移动允许按住连续触发，其余动作拒绝自动重复。
- 战斗状态：1 出招、2 防御、3 服药、4 撤退；拒绝自动重复，移动与野外服药快捷键不生效。战斗按钮仍支持鼠标、触屏和键盘原生激活。
- `src/main.js` 只负责执行路由返回的命令，`index.html` 标示战斗按键。
- `tests/controls.test.mjs` 新增 5 项独立回归测试；`npm run check` 增加新模块语法检查。

## 验收与边界

运行 `npm run check` 和 `python -m unittest discover -s tests -p 'test_*.py'`；最终 CI 结果以本轮提交对应的 GitHub Actions 为准。当前仅有纯函数的自动化单测，浏览器真实键盘、焦点和移动端行为仍需人工或端到端验收。

**所有输入规则、战斗键位和演示玩法均为独立原创实现，并非从 `jin.swf` 解析所得。** 本轮不增加已核实原作剧情事件，原作语义已核实仍为 0；FFDec 导出漂移根因仍待排查。PR 继续 Draft，原始 SWF、音视频、美术不修改或再分发。
